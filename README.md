# Expensio

**A simple way to track what you spend.**

<br clear="left" />

Expensio is an early-stage project for tracking personal expenses — logging
purchases, sorting them into categories, and seeing where the money actually
goes.

> **Status:** fresh start. This repository currently holds the project
> scaffolding (icon and docs). The application code is still being built, so
> there is nothing to install or run yet.

## Repository layout

```text
expensio/

```
